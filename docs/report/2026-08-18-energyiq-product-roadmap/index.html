08 · Management control

风险和价值必须一起管理

真正的风险不是功能少，而是工程结果没有转化为客户价值、AI 输出缺乏新意、跨项目复制带来维护分叉。

当前四个主要风险

HIGH
客户验收晚于工程交付Mitigation：使用 named-user 脚本、内容评分和多账户 UAT，形成签字证据。
HIGH
AI 正确但平庸，或发散但没有诚实标注Mitigation：区分 Observation / Inference / Hypothesis，保留创造性但明确不确定性。
MED
Ngee 变成 Preschool 的复制品Mitigation：只复用运行与治理合同，Section Pack 和管理问题保持项目专属。
MED
功能增长早于运营能力Mitigation：先完成 Admin readiness、Run trace、备份与回滚，再扩大 Agent 自主性。

用这些指标证明价值

Time to First Priority用户首次找到值得处理事项的时间。
Explore with AI conversion有多少 Insight 促使用户进入深入分析。
A→B conclusion movement新数据带来多少 retained / updated / new / removed。
Insight usefulness新颖性、清晰度、决策价值和复述率。
Method reuse被批准的方法在多少 Snapshot / Project 复用。
